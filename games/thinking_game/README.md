# Minijuego 3: Juicio y Toma de Decisiones (Thinking / Feeling Game)

- **Eje evaluado:** Pensamiento / Lógica ($T$) vs Sentimiento / Empatía ($F$).
- **Variable generada:** `Thinking Score` (rango $0.0$ a $10.0$).
- **Interpretación para el Modelo ML:**
  - Puntuaciones $\ge 5.0$ orientan hacia Pensamiento analítico ($T$).
  - Puntuaciones $< 5.0$ orientan hacia Sentimiento / Valores ($F$).
