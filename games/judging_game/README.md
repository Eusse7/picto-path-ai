# Minijuego 4: Estilo de Vida y Planificación (Judging / Perceiving Game)

- **Eje evaluado:** Juicio / Estructura ($J$) vs Percepción / Flexibilidad ($P$).
- **Variable generada:** `Judging Score` (rango $0.0$ a $10.0$).
- **Interpretación para el Modelo ML:**
  - Puntuaciones $\ge 5.0$ orientan hacia Estructura / Planificación ($J$).
  - Puntuaciones $< 5.0$ orientan hacia Flexibilidad / Espontaneidad ($P$).
